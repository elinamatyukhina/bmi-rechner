# BMI-Rechner

## Projektbeschreibung

Der BMI-Rechner ist eine Webanwendung zur Berechnung des Body-Mass-Index (BMI).
Der Benutzer gibt seinen Namen, sein Gewicht in Kilogramm und seine Größe in Zentimetern ein.
Ein Python-CGI-Skript berechnet den BMI und zeigt das Ergebnis im Browser an.

## Verwendete Technologien

- Python 3
- HTML5
- CSS3
- Git

## Projektstruktur

- index.html: Eingabeformular
- css/style.css: Gestaltung der Website
- cgi-bin/bmi.cgi: Berechnung und Ausgabe des BMI
